# Code map

One line per file.

## Top level

- `README.md`: what the project is, quickstart, ER diagram, query catalogue, test and performance summary, porting notes, limitations.
- `CODE_MAP.md`: this file.
- `LICENSE`: MIT licence.
- `pyproject.toml`: project metadata (standard library only, Python 3.11+).
- `.gitignore`: ignores databases (`*.db`), `__pycache__/` and the `var/` output folder.
- `.github/workflows/ci.yml`: runs the unit tests and a command-line smoke test on Python 3.11, 3.12 and 3.13.

## `talentsql/` (Python package, standard library only)

- `talentsql/__init__.py`: package marker and version.
- `talentsql/__main__.py`: lets `python -m talentsql` start the command line.
- `talentsql/cli.py`: the `seed`, `list`, `run`, `explain`, `bench` and `report` commands.
- `talentsql/db.py`: connects to SQLite, applies the schema and indexes, reads the query files and their header comments, formats tables.
- `talentsql/seed.py`: reproducible synthetic data generator (a fictional company) and the idempotent database builder.
- `talentsql/bench.py`: times queries with and without secondary indexes, captures query plans, writes `docs/PERFORMANCE.md`.
- `talentsql/report.py`: writes `docs/SAMPLE_REPORT.md` from the real output of every query.

## `sql/`

- `sql/schema.sql`: tables, keys, constraints and the stage reference data.
- `sql/indexes.sql`: secondary indexes, kept separate so the benchmark can drop and re-create them.
- `sql/queries/01_funnel_by_stage.sql` to `sql/queries/28_manager_attrition_and_ratings.sql`: the 28 numbered analytic queries, each starting with a comment block (business question, tables, technique, edge cases). The catalogue in `README.md` lists them all.

## `tests/`

- `tests/__init__.py`: makes `tests` importable so the suite runs with `python -m unittest discover -s tests -t .`.
- `tests/fixture.py`: the small deterministic dataset, and helpers that build a seeded database for tests.
- `tests/oracles.py`: independent plain-Python versions of all 28 queries, used to check the SQL.
- `tests/support.py`: row comparison helper and small builders for hand-sized scenarios.
- `tests/test_queries.py`: one differential test per query, run on the fixture and on a generated database, plus result-order tests.
- `tests/test_behaviour.py`: literal-value scenarios, constraints, suppression, adverse-impact maths, org-tree loops, islands, seeding, data quality, CLI and benchmark tests.

## `docs/`

- `docs/QUERY_GUIDE.md`: each technique explained in plain words with the exact SQL that uses it.
- `docs/PERFORMANCE.md`: generated by `bench`; environment, timings before and after indexes, and query plans.
- `docs/SAMPLE_REPORT.md`: generated by `report`; the output of every query on the sample data.
